# Socket.IO Chat App (React + Vite)

A modern, responsive chat application frontend built with React, Vite, and CSS.

## Features

- **Authentication Flow**: Mock register, OTP verification, and login steps.
- **Chat Interface**: Dark mode chat window with interactive sidebar, user status indicators, and typing notifications.
- **Messaging**: Private and group chat support with smooth auto-scrolling.
- **Group Management**: Create groups and view member lists.

## Getting Started

### Installation

```bash
npm install
```

### Development

Run the development server with HMR:

```bash
npm run dev
```

### Production Build

Build the project for production:

```bash
npm run build
```
